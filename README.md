E-Commerce Website

Overview

This project is a fully functional e-commerce website built using a pre-designed template. It includes features such as product listing, shopping cart, user authentication, and order management. The website is developed using PHP for backend functionality, along with HTML, CSS, JavaScript, AJAX, and jQuery for the frontend.

Features

User registration and authentication

Product catalog with categories and filters

Shopping cart functionality

Secure checkout process

Order management system

Responsive design for mobile compatibility

AJAX-based dynamic content updates

Technologies Used

Backend: PHP

Frontend: HTML, CSS, JavaScript

AJAX & jQuery: For seamless user interactions

Database: MySQL

Template: Pre-designed HTML/CSS/Bootstrap template

Installation

Clone this repository:

git clone https://github.com/Atamasc/Sito-e-commerce.git

Set up your database:

Create a MySQL database.

Configure the database connection in inc/db-conn.php:

Start a local server (e.g., using XAMPP or MAMP).

Open the project in a web browser:

http://localhost/ecommerce-project

Usage

Register or log in as a user.

Browse products and add them to the cart.

Proceed to checkout and complete the purchase.

Admin can manage products and orders through the backend.
